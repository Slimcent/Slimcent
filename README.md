# Hi, I'm Obinna Achara

Backend Software Engineer working mainly with **C#, ASP.NET Core, Python and FastAPI**.

I build backend systems around APIs, asynchronous processing, distributed workflows, authentication, payments, observability and data-intensive applications.

I currently work at the **Paderborn Center for Parallel Computing (PC²)**.

---

## Current Focus

### FlowForge

I am currently building **FlowForge**, a backend platform for workflow execution and distributed job processing.

The project is being developed in stages, starting with the execution core and worker infrastructure before moving into document intelligence.

```
FlowForge Core
    ↓
Workflow Execution
    ↓
RabbitMQ + Workers
    ↓
Retries and Reliability
    ↓
Stable FlowForge API
    ↓
Document Intelligence Platform
    ↓
FlowForge Integration
    ↓
Python / FastAPI Document Worker
```

The main focus is reliable asynchronous execution, worker processing, retry handling and clear workflow state.

## Featured Project

### Online Voting System

[Repository](https://github.com/Slimcent/Online_Voting_Sys) · [Live API](https://online-voting-api.runasp.net/swagger/index.html)

A backend election platform built with **ASP.NET Core, Entity Framework Core and SQL Server**.

It covers:

- election setup and election positions
- candidate applications
- application payments
- administrative review
- contestant management
- voter registration
- secure vote casting
- voting history
- election results
- JWT authentication
- refresh-token rotation
- role- and claims-based authorization
- caching
- background processing
- audit trails
- OpenTelemetry instrumentation
- Prometheus metrics
- Grafana dashboards
- Tempo distributed tracing
- NLog application logging

The project follows a layered architecture with thin controllers, service interfaces and implementations, repositories, Unit of Work and infrastructure abstractions.
